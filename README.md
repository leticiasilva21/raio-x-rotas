# Raio-X de Rotas · Carpediem

Painel interno para decidir quais imóveis da base custam mais do que rendem: receita (Stays), chamados (Jestor), rotas e desvio de rota (roteirização com OSRM), verticalização por endereço e roteirizador com ponto de partida.

Acesso restrito a contas @carpediemhomes.com.br. Os dados ficam no Supabase (snapshot lido pela função `pricing_raio_x_rotas_get`); este repositório só tem o código da página.
